# myNonameExtension

无名杀（noname）扩展「自写功能」——个人自用的功能增强与内容扩展合集。

## 内容

- **将池**（`自写功能/将池/`）：自定义武将、技能与卡牌；技能按无名杀事件系统实现（`trigger` / `filter` / 异步 `content`），并为 AI 提供可用的估值函数。
- **突破系统**（`自写功能/TUPO2/`）：武将与技能的突破版本，含动态翻译。
- **游戏模式**（`自写功能/mode/`）：斗地主与身份模式的选将、身份分配流程。
- **界面与工具**（`自写功能/*.js`、`1.css`）：手牌数统计、牌堆与回合提示、联机旁观聊天、弹幕、座次编号、黑名单等自用功能。
- **自定义功能**（`YDDIY.js`、`diyfunc.js`、`contentChange.js`）：技能交互改写、联机同步（`client.ws.send` 下发扩展数据）等。

## 安装

1. 将 `自写功能` 目录放入无名杀的 `extension/` 目录；
2. 启动游戏，在「扩展」中启用「自写功能」；
3. 依赖同目录的 `noname.js` 与 `noname/library/*`（随游戏本体提供），无需另行安装。

## 说明

- 代码为个人自用扩展，接入无名杀本体的模块与事件接口，不含游戏本体资源。
- 部分界面功能默认关闭，可在扩展设置里开关。
- 仅用于个人游玩与学习，游戏本体版权归无名杀作者所有。
