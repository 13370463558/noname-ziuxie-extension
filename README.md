# myNonameExtension · 无名杀「自写功能」扩展

个人开发的[无名杀](https://github.com/libccy/noname)（开源三国杀网页版）扩展，包含自定义武将/技能、独立将池、突破系统、两种自建游戏模式，以及一批自用的界面增强工具。

## 功能

| 模块 | 内容 |
|---|---|
| `将池/` | 自定义武将与技能、独立将池、卡牌；技能按本体事件系统实现（`trigger` / `filter` / 异步 `content`），并附带 AI 用的估值函数 |
| `TUPO2/` | 武将与技能的「突破」版本，含动态翻译 |
| `mode/` | 自建「斗地主」与身份模式的选将、身份分配流程 |
| `YDDIY.js` / `diyfunc.js` / `contentChange.js` | 技能交互改写、内容替换、联机同步（`client.ws.send` 下发扩展数据） |
| `1.css` + 各工具脚本 | 手牌数统计、牌堆与回合提示、联机旁观聊天、弹幕、座次编号、黑名单等界面功能 |

规模：26 个 ES Module，约 1.7 万行 JavaScript。

## 安装

1. 把 `自写功能` 整个目录放进无名杀的 `extension/` 目录；
2. 启动游戏，在「扩展」中启用「自写功能」；
3. 依赖游戏本体提供的 `noname.js` 与 `noname/library/*`，无需另外安装。

部分界面功能默认关闭，可在扩展设置里开关。
